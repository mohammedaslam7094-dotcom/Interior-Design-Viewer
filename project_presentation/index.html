Abstract

The Interior Design Viewer bridges the gap between imagination and reality. Use your own room photos to visualize premium materials before buying.

The Problem

Traditional catalogs are static. Clients struggle to visualize how a specific flooring or wall texture will look in their actual space.

The Solution

An interactive Web Visualizer allowing users to upload room photos, define surfaces, and apply textures in real-time.

Frontend

HTML5, Tailwind CSS, Canvas API

Backend

PHP (Core), Routing System

Database

MySQL (Relational)

Security

Bcrypt Hashing, Session Mgmt

System Modules

User Portal

  • Home & Featured: Landing page with trends
  • Material Gallery: Texture browser with filters
  • Visualizer: Interactive room editor
  • Budget Planner: Cost estimator

Admin Portal

  • Dashboard: Analytics & Stats
  • Inventory: CRUD for Materials/Categories
  • Quotes: Manage pricing requests
  • Reviews: Moderate user ratings

Key Technical Features

The Visualizer Engine

Core renovation tool using Canvas API.

  • Image Upload: Handles high-res user photos.
  • Polygon Tool: Click-to-draw selection logic.
  • Blending Mode: Uses 'Multiply' blend to preserve shadows & realism.

Budget Planner

Financial estimation logic.

Total = Area(sqft) × Material_Price

Automatically fetches live prices from the database to give accurate quotes based on user input dimensions.

Data Management

Backend PHP structure.

  • Routing: Clean URLs (no .php extensions).
  • Security: Input sanitization & SQL injection prevention.
  • Dynamic: Changes in Admin panel reflect instantly on User side.
